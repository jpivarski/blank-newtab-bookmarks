Privacy Policy — Blank New Tab + Bookmarks Bar

Last updated: August 2026

Blank New Tab + Bookmarks Bar is a Chrome extension that replaces the New Tab page with a minimal page showing a bookmarks folder chosen by the user.

What data the extension accesses

The extension reads the titles, folder structure, and URLs of the user's own Chrome bookmarks, using Chrome's bookmarks API, in order to display them on the New Tab page. The extension also retrieves favicons for bookmarked sites from Chrome's local favicon cache for display purposes.

What data the extension stores

The extension stores only the user's display preferences (theme, layout, selected bookmarks folder, favicon visibility, and link-opening behavior) using Chrome's built-in storage API. This is synced by Chrome itself across the user's own signed-in browser installations.

What the extension does not do

  • It does not transmit bookmarks, favicons, browsing history, or any other data to any server.
  • It does not use analytics, tracking, or advertising services.
  • It does not share, sell, or otherwise disclose any data to third parties.
  • It does not create, modify, or delete any bookmarks.
